One sentence, at most 200 characters, in the voice of an alien tourist giving planet Earth a one-star review while still slipping in a real compliment about the food. Entry for make.fun's "One Star, Five Stars for the Food" bounty: https://make.fun/c/u-po-pu-one-star-five-stars-for-the-food-f9166ee7

The review:

> One star: the gravity bruised my third knee, and I would cross the galaxy twice for your noodles.

One genuine grievance (Earth's gravity vs an alien's third knee), then the turn — the food compliment lands last, on the word "noodles".

## Run it

```sh
python3 main.py
```

`main.py` writes the sentence to `/output/entry.txt` (the path the make.fun program/v1 harness gates on; override with `ENTRY_OUTPUT`) and prints it to stdout. The output is byte-identical on every run.
